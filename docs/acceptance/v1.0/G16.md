## 前置条件

- 一台可以装抓包工具的 macOS 机器：`Little Snitch` / `Wireshark` / 系统自带
  `nettop` + `pfctl` 均可，记录用的是哪一种。
- 只在电脑上配置了要测试的模型厂商 Key（不要顺手开着其它抓包会误报的软件）。

## 步骤

1. 启动抓包工具，规则设为"记录但不拦截"（先要看见全部出站请求，再判断哪些
   合法）。
2. 安装并启动 Jones（若结合 G01 一起做，从全新安装开始）。
3. 正常使用 1 小时：多轮对话、切换 Session、跑一次 Cron、试一次浏览器工具
   （若已配置）、打开设置页各个面板。
4. 关闭 Jones（Electron 窗口 + 守护进程都关，或至少 Electron 关闭）。
5. 导出抓包记录，按目标 host 分组，逐条核对：这个 host 是不是用户自己配置的
   模型 API，或用户显式启用的外部服务（浏览器工具访问的网站不算——那是用户
   主动发起的浏览器导航，不是 Jones 自己的遥测）。

## 期望

- 除以下两类外，没有任何出站请求：① 用户配置的模型厂商 API host；② 用户在
  浏览器工具里主动导航到的网站。
- 没有任何指向已知遥测/崩溃上报服务商（Sentry、Mixpanel、Google Analytics 等，
  参见 `test_n06_no_telemetry.py` 的黑名单）或任何"看起来像自动上报"的未知
  host（周期性、固定间隔、无用户操作触发的请求尤其可疑）。
