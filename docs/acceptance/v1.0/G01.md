## 前置条件

- 一台全新 macOS 13+ 机器（Apple Silicon 或 Intel），或至少一个全新用户账户 /
  全新 `~/.jones/` 都不存在的环境（`rm -rf ~/.jones` 不等价于"全新机器"，但可以
  作为退而求其次的近似——如实标注用的是哪一种）。
- 从头到尾**不预先配置任何环境变量、不手动创建 `~/.jones/`**。

## 步骤

1. 拿到发布产物 `Jones-<version>-<arch>.dmg`（见 `docs/release.md` §2），拖到
   `/Applications`，双击启动 `.app`。
2. 记录从双击到窗口出现的整个过程里，是否在任何一步看到以下任一 UI：注册表单、
   登录表单、Apple ID / 第三方账号登录按钮、订阅/付费墙、"跳过登录"这类暗示
   存在登录选项的按钮。
3. 走到设置页，配置至少一家模型厂商的 Key（G02 覆盖多厂商细节，这里只需要
   一家能跑通）。
4. 发起第一轮对话，等待完整回复。
5. 全程（步骤 1-4）截图或录屏留存。

## 期望

- 步骤 2 未出现任何注册/登录/订阅/付费墙相关 UI。
- 步骤 4 的首轮对话能正常完成（不是被账号墙拦住才能配置 Key）。
