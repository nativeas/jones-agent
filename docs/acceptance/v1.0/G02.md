## 步骤（每家厂商重复一遍）

1. 设置页 → Provider 设置 → 填入该厂商 Key → 保存。
2. 校验通过（若失败，记录明确提示文案，见「Key 校验失败有明确提示」FR04）。
3. 新建一个 Session，Session 级切换模型到该厂商的一个模型。
4. 发一条会触发至少一次工具调用的 prompt（例如"读一下当前目录有哪些文件"，
   触发 `read_file`/`search_files`）。
5. 等待 Turn 完整结束，记录：是否成功、工具调用是否真的执行、回复内容是否
   合理。

## 期望

- 六家厂商均能完成一次含工具调用的 Turn。
- Key 校验失败（如故意填错 Key）时有明确提示，不是裸错误码。
- Session 级切换模型后上下文不丢（同一 Session 换厂商，之前的对话仍在）。
