## 自动化用例

  `test_first_delta.py`、`test_idle_resources.py`）——`pytest -q` 默认收集，
  `make check-daemon` 的一部分。

  `pnpm run build`）。

## 最近一次实测（本机，非参考机）

见 `docs/acceptance/v1.0/perf-2026-09-19.json` 与 `docs/release.md` §1：
全部 8 项指标在 **Apple M4 / 32GB / macOS 27.0**（`is_prd_reference_machine:
false`）上实测通过。Electron RSS 余量很小（≈276MB / 300MB 阈值），发布前必须
在真实参考机（Apple M1/16GB 或 Intel i5 12 代/16GB）上重跑并核对。
